Disparate System Data Linkage

Python

A Python utility designed to parse, normalize, and match entity records between un-linked legacy systems using deterministic fuzzy matching logic. 

import pandas as pd

def normalize_key(val):
    if pd.isna(val): return ""
    return str(val).strip().lower()

# Match records across disparate systems
df1['join_key'] = df1['email'].apply(normalize_key)
df2['join_key'] = df2['primary_email'].apply(normalize_key)

merged_df = pd.merge(df1, df2, on='join_key', how='inner')
print(f"Matched {len(merged_df)} records across systems.")

Salesforce SOQL Data Extraction

SOQL / Salesforce

Custom SOQL query structures used to extract relational user activity logs and case history metrics for SLA compliance reporting. 

SELECT Id, CaseNumber, Subject, Status, CreatedDate,
       (SELECT Id, StepStatus, OriginalActor.Name
        FROM ProcessSteps
        WHERE StepStatus = 'Approved')
FROM Case
WHERE CreatedDate = LAST_N_DAYS:30
  AND Status IN ('In Progress', 'Escalated')
ORDER BY CreatedDate DESC

REST API Integration Payload Handler

JavaScript / JSON

Lightweight middleware script handling webhook payloads from webform integrations (e.g., Alchemer) to route parameters cleanly into ITSM ticket queues. 

async function handleWebhook(payload) {
    const formattedData = {
        title: `[Webform] ${payload.survey_title}`,
        description: payload.response_summary,
        requested_by: payload.respondent_email,
        priority: payload.urgency || 'Medium'
    };

    // Dispatch to ITSM Endpoint
    return await fetch('https://api.itsm.internal/v1/tickets', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(formattedData)
    });
}
